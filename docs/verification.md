## v0.2.1 桌面嵌入修复

安装后的本机管理服务可直接访问并返回 HTTP 200，但 Windows 桌面使用 `http://wails.localhost`，原管理页的 `frame-ancestors` 只包含 `127.0.0.1` 和 `localhost`，导致浏览器拒绝嵌入。独立 Chromium 在相同桌面来源及 `allow-scripts` 沙箱下复现了 `ERR_BLOCKED_BY_RESPONSE` 和明确的 CSP 报错；仅补入桌面来源后，页面成功加载并显示「管理服务在线」。浏览器自动化单独授权测试来源的本地网络访问，以便区分 Chromium 的本地网络权限与本次 CSP 问题，不修改用户的浏览器或 Magpie 权限。

新增回归用例已先复现失败，再在修复后通过。实际 v0.2.1 包解压后的管理服务在桌面来源、普通回环网页中均成功加载并显示在线；无关网站的嵌入继续被 CSP 拒绝。修复只补充这一项父页面来源；服务仍仅监听回环地址，API 的 Origin、Host 与随机标识认证保持原有规则。用户日常 Magpie 的插件宿主须重新加载后才会使用新代码。
