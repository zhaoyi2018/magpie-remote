## 新建 SSH 连接弹窗重构

2026-10-22 在独立 Edge 浏览器、本机临时 SSH 服务和临时配置目录中验证了新建弹窗：SSH agent、私钥文件、密码环境变量、临时密码、保存并连接、编辑回填与只保存修改、必填校验、关闭后重置和认证方式的键盘切换。测试确认密码原文未写入配置。管理页 CSP 沙箱会拦截原生表单提交，因此保存按钮和输入框回车通过 JavaScript 处理；保持原有沙箱策略。

提交前将弹窗逻辑和样式独立为模块，并在当前已提交基线加本次功能的隔离副本中验证：Node 与 Bun 1.4.3 均为 31/31，浏览器的按钮与回车提交、三种认证、编辑回填及明暗/窄屏布局通过；实际 Magpie 宿主完成 10 个工具注册、SSH 认证、c2s/s2c 数据往返及端口释放。其他尚未提交功能不属于该提交。

## 尚未验证的场景

- 用户生产服务器的凭据、网络、防火墙及 sshd 转发策略。
- Windows OpenSSH agent / Pageant 与具体密钥组合的实机登录。
- 生产环境的加密私钥格式、主机证书、IPv6 与非回环远端监听策略。
- 用户日常 Magpie 窗口中的最终安装体验及具体 Agent 的 MCP 接入；本次使用独立插件宿主和浏览器内嵌测试环境。
- 多个宿主同时写入同一配置文件，或自动断线重连；当前不提供这些能力。

`connected` 证明 SSH 握手、信任和认证已完成；`listening` 证明转发监听已建立。它们不等同于目标业务应用健康。测试中的真实数据往返只证明对应测试目标的链路。

测试来源为 Git 仓库中的 `tests/sessions.test.mjs`、`tests/plugin.test.mjs`、`tests/store.test.mjs`、`tests/host-keys.test.mjs` 和 `scripts/host-smoke.mjs`，这些开发文件不随 npm 包发布。返回[文档导航](README.md)。
