# 远程 Magpie 管理

连接 SSH 后，在「远程 Magpie」页检测当前登录用户的环境。首版支持普通 Linux amd64/arm64 的用户安装：安装、更新、用户服务启停、启用官方管理页面和保留配置的卸载。供应商与 Agent 通过官方管理页面操作；插件内的独立编辑界面尚未加入。

## 使用流程

1. 建立 SSH 连接，打开「远程 Magpie」，点击检测环境。SSH 已连接与 Magpie 正在运行是独立状态。
2. 未安装时预览安装。后台从官方 `https://usemagpie.ai/api/latest` 读取 CLI 资产 URL 和 SHA-256；远端下载后校验，再安装到 `~/.local/bin/magpie`。本步骤不启动服务。
3. 已安装程序但尚无用户服务时，先点击「启用 Web」，预览后创建并启动当前用户的 systemd 服务，再使用服务启停按钮。网关使用回环地址，管理页面使用 `127.0.0.1:3430`。无 systemd 用户会话时保留程序安装，服务操作会明确拒绝。
4. 获取管理链接。后台显式读取 `magpie daemon web` 的回环链接，并建立随机本地端口到远端 Web 端口的 c2s 转发。将链接复制到外部浏览器访问官方页面，管理供应商和远端当前用户下的 Agent。保持 SSH 连接；断开后本地入口失效。

管理链接携带有权限修改远端配置、查看供应商密钥的 Web key，不要分享。它与模型调用使用的 gateway key 不同。链接只在显式请求后返回，不进入操作记录或本地 SSH 配置；切换连接和页面退出时清空显示。`magpie-web` 是此入口使用的临时转发标识，同名其他规则不会被覆盖。停止服务或卸载完成后，自动关闭本入口创建的转发、释放活跃通道并清除自动重连意图；SSH 与其他转发保持连接。检测环境确认服务已在外部停止或 Web 已禁用时也会清理此入口，页面同步清空旧地址。

默认 Gateway 模式会隐藏 Agent 页面；需要管理远端 Agent 时，在远端官方页面的通用设置关闭 Gateway 模式。Agent 指远端已安装或已配置的 CLI/桌面工具，各工具的字段和生效条件不同，并非通用远程任务或进程管理。

## 更新与备份

检测环境时只读执行当前程序的 `--help`，分别确认更新、备份、恢复、健康检查及用户服务命令，并从官方发布清单比较当前版本。仅确认存在较新版本时显示「更新 Magpie」；当前版本相同或更高时显示无需更新，版本无法识别或清单读取失败时显示待核实与重试入口，不影响其他服务操作。旧版如 `0.1.1327` 只要提供所需命令，也可更新或启用服务；缺少的具体命令会显示在对应按钮提示中。旧的环境缓存需要重新检测以取得版本和能力信息。

创建备份、更新前备份和恢复前备份统一使用远端 `tar` 保存 `config.tar.gz`，不调用官方加密备份命令，也不要求备份口令。**此归档未加密，可能包含供应商密钥和登录信息**，保存在权限为 `0700` 的本次操作目录。配置目录不存在时写入 `config.absent` 记录；配置存在但无法备份会拒绝继续。

更新必须先完成配置归档并复制旧程序，然后才执行 `magpie update`。备份失败会阻止更新。原服务正在运行时才重启并检查健康状态；原停止状态不主动启动。「创建备份」仅保存配置和程序，不更新程序或重启服务。备份目录为 `${XDG_CONFIG_HOME:-$HOME/.config}/magpie-remote/backups/<操作 UUID>/`，包含相应配置备份、旧程序 `magpie` 和版本记录。请妥善管理归档，并按需转移备份；本插件不自动删除远端备份。

「远端备份」可读取本插件生成的备份，显示创建时间、版本、格式、大小与是否包含程序副本，并支持手动创建、恢复配置和删除。列表只读取元数据和校验值，不返回备份内容。创建和删除均先预览；删除仅处理本插件备份目录中的选定 UUID 条目，卸载程序后仍可清理备份。已存在的更新备份也会出现在列表，旧备份没有版本记录时显示未知。

配置归档和无配置目录快照支持自动恢复。先保存恢复前的配置归档与当前程序，在独立临时目录中校验并展开所选归档；确认可用后才停止原先运行的服务并替换配置目录。无配置目录快照会移除当前配置目录。替换失败时尝试还原原目录；恢复成功后仅重新启动原先运行的服务并检查健康状态，原停止状态保持停止。归档无效或包含越界路径时，在停止服务和替换配置之前拒绝执行。预览绑定选定条目的文件校验值，内容变化时拒绝执行。

恢复会替换整个配置目录，保留当前程序版本，配置目录以外的数据不会随归档恢复。旧程序副本不代表跨版本配置一定可以降级，页面不提供自动回退二进制。历史 `config.magpie` 加密备份仍显示在列表并可删除，需要使用原工具和原口令手动恢复；不完整备份不能自动恢复。

## 操作进度与断线

变更必须先读取预览，再提交其短时 revision。提交前复核连接配置、程序哈希与服务文件哈希。相同 revision 重复提交返回同一任务；同一连接同一时刻只执行一个变更。页面刷新不取消后台任务，也不会自动重发安装或更新。

远程页顶部的任务摘要实时显示备份、更新、重启与健康检查等阶段。安装和更新期间约每秒采样一次远端下载文件，页面约每 2 秒显示已下载大小与采样速度；安装清单提供可信文件大小时同时显示百分比。官方 `magpie update` 不输出总大小，更新显示实际已下载量和速度，不推算百分比。若该版本使用未识别的临时路径，则仅显示执行阶段。换阶段、完成、失败、结果未知或 SSH 断开后停止显示活动下载信息。下载字节只更新当前任务快照，阶段变化才写入运行日志。

远程操作的提交、执行、成功、失败和断线待核实事件写入当前连接的「运行日志」，与 SSH、转发事件一起过滤和查看，保留最近 200 条，宿主重启后清空。失败步骤、退出码、分类原因和已完成的备份位置合并到对应日志条目，不另设重复任务详情区；远程页面仅保留任务摘要与日志入口。原始命令输出和 Web 管理密钥不进入运行日志。

本地 `connections.json.remote.json` 保存最近环境与每个连接的最新任务；文件损坏时明确报错，不覆盖旧内容。插件重启后原运行任务标为结果待核实。远端使用 `magpie-remote/operation.lock` 互斥，将状态写入 `magpie-remote/operations/<UUID>/state`，并在 `result` 中记录操作标识、失败步骤、退出码、可识别的错误类别与备份完成标记。只有固定字段返回页面，不保存命令的原始输出或口令。

SSH 断开、超时、通道没有明确退出码时，变更任务标为结果待核实。重新连接后检测环境，只有取得远端明确的完成记录并确认操作锁已释放，才解除状态。不根据版本或服务看似正常就自动重试。若锁残留或记录缺失，请在服务器核实进程与变更，不要直接重复部署。关闭 SSH 通道不能保证远端进程一定终止。

有运行中或待核实任务时不能删除连接或恢复全局 SSH 配置。待核实任务允许更新同一服务器的 SSH 凭据以便重新连接，不能把这条连接改指向另一台服务器。

## 更新失败时排查

页面显示失败步骤和退出码，并在识别到网络、权限、磁盘空间、交互要求或不支持的命令时给出相应提示。备份或旧程序复制失败会注明尚未执行更新；更新命令完成后若重启或健康检查失败，会提示先检查当前版本与服务，不要直接重复更新。配置和旧程序都已保存时，即使后续步骤失败，页面仍显示备份目录。

只显示“退出码 1”的旧任务无法还原具体原因，检测环境也不会自动重新执行它。先检查远端记录，可在服务器执行以下只读命令，将 `<操作 UUID>` 替换为页面的任务标识：

```sh
base="${XDG_CONFIG_HOME:-$HOME/.config}/magpie-remote"
cat "$base/operations/<操作 UUID>/state"
cat "$base/operations/<操作 UUID>/result"
ls -lh "$base/backups/<操作 UUID>/"
"$HOME/.local/bin/magpie" --version
systemctl --user is-active magpie.service
```

旧任务没有 `result` 文件时，文件不存在是预期现象。`config.magpie` 或 `config.tar.gz` 存在只能说明相应备份文件已生成；同时存在旧程序 `magpie` 才表示更新前的两步备份都已完成，仍不能证明更新命令成功。请勿直接分享备份文件，其中可能包含供应商密钥。普通 `magpie update` 不要求终端或 `--yes`；退出码 1 本身不能区分配置读取、下载、校验、写盘与服务检查错误。若任务明确显示「执行官方更新」及网络错误，表示失败发生在更新阶段；移除备份口令不会修复服务器到下载源的连接。

## 卸载与支持边界

自动卸载只接受当前用户 `~/.local/bin/magpie` 的非符号链接普通文件，先通过官方命令移除已安装用户服务，再删除程序。保留供应商配置、登录信息与备份。卸载前通过官方页面恢复仍接入该网关的 Agent，插件不会自动改写各 Agent 配置。

首版不接管系统路径、包管理器安装、容器或 system 服务；不运行 sudo，不自动开启 linger。用户服务能否在退出 SSH 后持续运行取决于服务器的用户会话和 linger 设置。命令形式按 Magpie 0.1.1472 及 0.1.1476 官方资料核对，并以当前二进制的帮助信息确认所需命令。帮助未列出所需命令或参数时仅禁用相关操作；这不代表所有版本的运行行为均已实机验证。

预览与哈希复核可以发现部分并发变化，但不是与其他 Magpie 进程共享的事务锁。操作期间不要同时从另一个客户端修改同一安装。后台只调用固定操作，不提供任意 shell 工具。

## 工具接口

| 工具 | 参数 | 结果 |
| --- | --- | --- |
| `remote_status` | `connectionId`、可选 `refresh` | 缓存环境与最新任务；`refresh: true` 连接后探测并核实未知任务 |
| `remote_preview` | `connectionId`、`action`；恢复或删除时加 `backupId` | `revision`、变更清单、提示、归档备份方式 |
| `remote_apply` | `connectionId`、`action`、预览的 `revision` | 立即返回后台任务，后续查询状态 |
| `remote_operation` | `connectionId`、可选 `operationId` | 此连接最新任务或 `null` |
| `remote_web` | `connectionId`、可选 `port` | 临时本地访问地址和带管理 key 的登录链接 |
| `remote_backups` | `connectionId` | 此连接的远端备份元数据列表 |

`action` 为 `install`、`update`、`start`、`stop`、`restart`、`enable_web`、`backup`、`restore`、`delete_backup`、`uninstall`。`remote_status` 同时返回各 `actions` 的 `enabled`、禁用原因与代码，以及 `update.state`（`available` / `current` / `unknown`）、版本与检查时间；涉及备份的 `remote_preview` 返回 `backupMode: "archive"`。恢复的 `backupId` 绑定在预览中，提交无需再次传入。远程操作不接收备份口令或独立凭据字段。
